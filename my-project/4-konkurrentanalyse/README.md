# Konkurrentanalyse

Faglærer anbefalte å gjøre en konkurrentanalyse, helst før PRD-en. Jeg gjorde den 27. oktober 2026, etter at product brief, PRD og UX var ferdige. Den er laget med BMAD-skillen `bmad-deep-recon` (typen «competitive»), der KI-en søkte på nettet og samlet funnene med kilder.

Analysen endrer ikke brief, PRD eller UX. Den sjekker om det som står under «Hva gjør dette annerledes» i briefen stemmer, og samler læringspunkter til arkitekturen og stories.

| Fil/mappe | Hva det er |
|---|---|
| [`konkurrentanalyse.md`](konkurrentanalyse.md) | Rapporten: sammendrag, funn om Jobscan, Rezi, Teal og Kickresume, anbefalinger og kilder |
| [`konkurrentanalyse-memlog.md`](konkurrentanalyse-memlog.md) | Beslutningslogg: planen jeg godkjente, kildene, påstandene og om de er bekreftet |
| [`sokenotater/`](sokenotater/) | Notatene fra hvert søk (én fil per konkurrent, og én fra runden som sjekket hullene), som rapporten er skrevet ut fra |
