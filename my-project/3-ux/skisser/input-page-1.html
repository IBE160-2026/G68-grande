Innleggingssiden – skisse

Prøv å laste opp en fil (velg hvilken som helst), lime inn tekst og tømme med søppelbøtta. Trykk «Sjekk CV-en min» med tomme felt for å se feilboksen. Filnavn som ikke slutter på .pdf gir «Feil filtype». Filnavn med skannet gir feilen for uleselig PDF, og filnavn med stor gir «Filen er for stor». Med «Svar fra KI» kan du prøve feilmeldingene når KI-en ikke svarer. I testmodus virker bare filnavn som begynner med test.
