# .claude (verktøy for Claude Code)

Denne mappen brukes av **Claude Code**, AI-assistenten du jobber med i terminalen.

- **`skills/`** inneholder BMAD-skills: ferdige arbeidsflyter og AI-roller (Mary, John, Winston osv.) som Claude kan bruke. De ble installert sammen med BMAD.

Du trenger ikke endre noe her. Skills startes ved å skrive navnet, for eksempel `/bmad-help`.
