# _bmad (BMAD-oppsettet)

Her ligger oppsettet for **BMAD**, arbeidsmetoden for å bygge programvare med AI. Alt her ble installert med BMAD, og du trenger vanligvis ikke endre noe.

| Mappe/fil | Hva det er |
|---|---|
| `config.toml` | Hovedinnstillingene (navn, språk, hvor dokumenter lagres). Lages på nytt ved ny installasjon |
| `custom/` | **Egne innstillinger** som ikke overskrives ved ny installasjon |
| `_config/` | Oversikter over hva som er installert |
| `bmm/`, `cis/`, `core/` | Innstillinger for de ulike BMAD-modulene |
| `scripts/` | Hjelpeprogrammer BMAD bruker i bakgrunnen |

**Utkast** som BMAD lager havner i `_bmad-output/` (bare på din PC). **Ferdige dokumenter** legger du i `my-project/`.
